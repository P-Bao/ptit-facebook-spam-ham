# Phân loại Spam/Ham bình luận sinh viên PTIT

Project của nhóm Bảo, Cương, Phi, Phương: thu thập và chuẩn bị bình luận Facebook,
thực nghiệm các mô hình phân loại, đánh giá và dự đoán bình luận mới.

- [Tổng quan project](docs/guides/TONG_QUAN_PROJECT_VA_CACH_THUC_THI.md): cấu trúc, vai trò từng module, luồng xử lý, cách chạy và đầu ra.
- [Notebook 01 — Thu thập và chuẩn bị dữ liệu](notebooks/01_thu_thap_va_gan_nhan.ipynb).
- [Notebook 02 — Thực nghiệm và ứng dụng](notebooks/02_thuc_nghiem_va_demo.ipynb).

Mở notebook trong repo và chọn môi trường Python 3.12 đã cài
`requirements/notebook.txt`. Notebook sử dụng các module trong `pipeline/`.
Phần mô hình hiện đại được giữ chỗ để triển khai sau.
