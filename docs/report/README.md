# Báo cáo học phần — chuẩn bị sau khi chốt code

Chưa viết báo cáo trong lượt tái cấu trúc. Theo ảnh đề, bố cục gồm tiêu đề, giới
thiệu bài toán, cơ sở lý thuyết, thực nghiệm/kết quả và tài liệu tham khảo.

Dùng kết quả thật ở `results/verified_run/`, nguồn ở `docs/provenance/` và hai
notebook. Ý 4 bổ sung hiện có mục chờ, chưa ghi kết quả giả định.
