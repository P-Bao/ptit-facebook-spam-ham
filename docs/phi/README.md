# Tài liệu học phần mô hình truyền thống của Phi

Các file `00`–`07` là ghi chú học chi tiết được biên soạn từ **bản sao mã nguồn**
có hậu tố `(1)` ở thời điểm soạn. Tên file thật trong project không có hậu tố
đó. Khi cần đối chiếu hoặc chạy, dùng các file hiện hành trong
[`pipeline/modeling/`](../../pipeline/modeling/README.md) và
[`notebooks/02_thuc_nghiem_va_demo.ipynb`](../../notebooks/02_thuc_nghiem_va_demo.ipynb).

Thứ tự học: tổng quan → chia tập → BoW/TF-IDF → NB/SVM → GridSearchCV →
S1/S2/S3 → đánh giá → lưu và dự đoán. Các ví dụ và số liệu trong ghi chú là
minh họa tại thời điểm soạn; kết quả kiểm tra hiện hành nằm trong output của
Notebook 02 và `artifacts/spamham/` sau khi chạy lại. Đường dẫn tham chiếu tới
notebook hoặc model trong ghi chú có thể phản ánh bản sao đã dùng khi viết.

Nếu chỉ cần một luồng sát code hiện tại, đọc
[`PHI_DOC_CODE_THEO_LUONG.md`](../team/PHI_DOC_CODE_THEO_LUONG.md) và
[`pipeline/modeling/README.md`](../../pipeline/modeling/README.md) trước.
